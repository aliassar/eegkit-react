# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-11

The first release.

### Added

- `useEEG`: connects a source and runs eegkit's real-time pipeline on it.
- `useBandPowers`, `useTrace` and `useNeurofeedback` hooks.
- `syntheticSource`, `webSocketSource` and `manualSource`, and the `EEGSource` interface for
  writing your own sources.
